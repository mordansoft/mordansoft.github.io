# mordansoft.github.io

Public website for MordanSoft — company info, product pages, and legal documents (Privacy / Terms) for our products.

Live at: https://mordansoft.github.io/

## Structure

- `index.html` — company landing
- `aok/` — product page for AoK (Angle of Knife)
- `legal/aok/` — Privacy & Terms for AoK
- `legal/sloviko/` — Privacy & Terms for Sloviko
- `assets/` — CSS, images
- `app-ads.txt` — AdMob verification (do not move or delete)

## Local preview

Any static server works. Example:

```
python3 -m http.server 8000
```

Then open http://localhost:8000/.
