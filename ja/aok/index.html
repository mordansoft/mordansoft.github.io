// 包丁研ぎの角度計

研ぎながら、正確な角度がわかる。

スマホを刃の上に置くだけ。AoK が刃と砥石のあいだの角度をリアルタイムで読み取り、目標の角度になった瞬間に音で知らせます。包丁ごとの角度、鋼材、研ぎの履歴も、ひとつの記録にまとまります。

オフライン優先 アカウント不要 12言語対応 iPhone、iPad、Android
// 使い方

4ステップで、よく切れる刃に

作業台も、角度固定ホルダーも、勘も要りません。角度はずっと画面に出ています。

1

クイック研ぎを開く

先に包丁を登録しなくても、メイン画面からすぐ始められます。記録から包丁を選ぶこともできます。

2

目標の角度を決める

数字を入力するか、包丁の種類に合わせたプリセットを選びます。両刃の場合は、アプリが半分の角度を目標にしてくれます。

3

スマホを刃に置く

刃を砥石の上で動かすあいだ、角度計がいまの角度を表示します。

4

耳で研ぐ

目標に合うと、アプリが音で知らせ、画面が緑になります。目は刃先に向けたままでOK。終わると、その研ぎは包丁の履歴に残ります。

// アプリの中身

研ぎに必要なものを、ひととおり

リアルタイム角度計

スマホを刃の上に置くと、動かすたびに更新される正確な研ぎ角度を読み取れます。砥石、角度固定ホルダー、ベルトシャープナー、グラインダーに対応。斧、のみ、かんなの刃にも使えます。

音声ガイド

目標の角度を決めておくと、刃が正しい位置に来た瞬間にアプリが音で知らせます。数字を確かめるために刃先から目を離す必要はありません。

隙間計算機

ホルダーがないときは、刃の幅と狙いたい角度を入力します。砥石から峰をミリ単位でどれだけ浮かせればよいか、それを支えるのに硬貨が何枚いるかを表示します。

鋼材ガイドとお手入れのコツ

刃に刻まれた鋼材名を選びます。硬さ、切れ味の持ち、粘り強さ、錆びにくさ、研ぎやすさがわかり、その鋼材に合ったお手入れの方法や、いまの角度の刃が何に向いているかも案内します。

VG-10X50CrMoV1514C28N8Cr13MoV440CAUS-8

砥石がなくても、マグカップで

陶器のマグカップの、釉薬のかかっていない底の輪で研ぐ手順をガイドします。使えるマグカップの選び方、保つ角度、刃の動かし方、片側にかける時間、かえりの取り方まで。まっすぐな刃用です。波刃には別の道具が必要です。

包丁の記録とリマインダー

どの包丁も、角度、鋼材、写真といっしょに記録。研ぎはすべて履歴に残ります。研ぎどきが来たら、アプリがお知らせします。

// 制作事例

コンセプトからストア公開まで

背景

MordanSoft の主力プロダクトです。ほかの角度計アプリは数値を示すところまで。目標、ガイド、鋼材、記録という研ぎの一連の流れは、表計算や記憶に任されたままでした。

やったこと

デザイン、Flutter での実装、センサーフュージョンによる角度エンジン、音声ガイド、鋼材ガイド、包丁の記録、新しい購入画面を備えた Free/Premium の分離、12言語対応、スマホとタブレットのレイアウト、そして Google Play と App Store でのリリース。

数字

Google Play と App Store で公開中。12言語、スマホとタブレットに対応しています。Free/Premium の分離の効果は計測中です。
